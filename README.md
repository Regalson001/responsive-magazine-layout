# Responsive Magazine Layout

A modern, responsive editorial magazine web page styled using advanced CSS Grid techniques, custom design variables, and media queries for multi-device support.

## 🚀 Features

- **CSS Grid Architecture:** Two-dimensional layout control utilizing explicit row/column definitions, fraction units (`fr`), and spanned grid placement (`1 / -1`).
- **Responsive Media Queries:** Step-down breakpoint adjustments at 720px, 600px, 550px, and 420px to ensure seamless scaling across mobile and desktop displays.
- **Pseudo-Elements:** Dynamic quote formatting utilizing CSS `::before` and `::after` content injection.
- **Custom Typography:** Integrated typography pair featuring Anton, Baskervville, and Raleway Google Fonts.

## 🛠️ Built With

- **HTML5:** Semantic document markup (`<main>`, `<header>`, `<section>`, `<article>`, `<aside>`)
- **CSS3:** Custom properties, CSS Grid, Flexbox, and Media Queries
